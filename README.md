# proyecto-de-an-lisis-de-comportamiento-de-usuario-y-experimento-AAB

Este proyecto analiza el comportamiento de los usuarios de una aplicación de venta de productos alimenticios. El objetivo es doble:

1. Optimización del Funnel: Identificar en qué etapa del proceso de compra se pierden más usuarios y entender el flujo de conversión.

2. Validación de Rediseño (Test A/A/B): Evaluar si un cambio en las fuentes de la aplicación impacta la conversión, asegurando la fiabilidad del experimento mediante dos grupos de control.
